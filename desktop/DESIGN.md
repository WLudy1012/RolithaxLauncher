# Windows 工作区设计约定

- 以远端实例任务为中心：先选择连接和实例，再进入概览、控制台、文件、配置及资源等操作。危险操作说明影响并要求确认。
- 保留系统窗口的拖动、缩放和窗口控制；Windows 标题栏随系统浅色或深色模式调整。主题跟随系统。初始尺寸按屏幕可用工作区计算并保留边距，最大为 1280 × 840 dp。
- 使用中性浅灰背景、白色表面和蓝色强调色；深色模式使用深灰表面、浅色文字和亮蓝强调。状态和错误使用文字与颜色共同表达。
- 正文以 15–16sp 为主，辅助正文为 14sp，标签不小于 13sp；标题使用清晰的字号和字重层级。Windows 优先使用系统 Segoe UI，缺失时回退到微软雅黑 UI 或系统无衬线字体；中文缺字由系统字体回退，终端优先 Consolas。Linux 使用系统无衬线和等宽字体。
- 常规控件圆角 4–6dp，内容卡片约 12–14dp，以间距和细边框分隔内容。侧栏以较大的品牌标识开头，提供概览、实例管理、新建实例、用户管理和 Daemon 连接入口。
- 概览分为欢迎、节点概况、资源监控和快捷操作；只显示当前连接、实例数量及监控实际提供的数据，缺失或过期的数据需标明状态。
- 实例列表使用可滚动的全宽卡片，展示名称、状态、目录和核心，提供控制台、启停、文件管理及设置入口。实例详情的顶部显示当前实例与状态，下方以页签切换操作；窄窗口时卡片内容换行，主要操作仍可访问。
- 保持 150% 显示缩放下的可读字号、滚动和布局，尊重系统 DPI，避免强制固定 UI 缩放；跨显示器 DPI 切换仍需要真实设备验证。
- 明确显示连接、加载、空结果、操作结果和错误；控制台提供键盘输入、历史、搜索、跟随和复制。
- 文件和配置的未保存修改在导航时需要确认；对可能递归删除的目录明确提示不可撤销。

页面层级参考 [MSLX Desktop](https://github.com/MSLTeam/MSLX/tree/dev/MSLX.Desktop) 和 [MSLX WebPanel](https://github.com/MSLTeam/MSLX/tree/dev/MSLX.WebPanel) 的管理流程，界面由本项目使用 Compose 独立实现。远端能力仍按实际接口和实现逐步完善，不代表已与 Android 或官方客户端全功能对齐。
